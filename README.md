# Notes

Личное offline-first приложение для расписания, дел и свободных заметок. Данные
сразу сохраняются в IndexedDB текущего браузера и затем синхронизируются с личным
сервером. Потеря сети не блокирует работу.

Production: <https://notes.135-106-167-202.sslip.io>

## Быстрый старт

Требуется Node.js 22.13 или новее.

```sh
npm install
npm run preview
```

Команда собирает и запускает полное приложение и печатает локальный адрес вида
`http://2026-09-07.preview.localhost:8788`. Пароль — `preview`. При первом
запуске она создаёт в `.local-preview` локальную базу с расписанием, делами,
заметками, шаблонами и историей. В течение дня следующие запуски сохраняют
изменения из предыдущего тестирования, а с новой датой обновляют относительные
дни демо-набора и меняют локальный origin, чтобы браузер не подмешивал вчерашнее
offline-состояние. Эта база не попадает в Git и не связана с production.

Для разработки клиента с hot reload по-прежнему доступны `npm run dev` и
`npm run dev:client`; серверу нужны переменные из `deploy/.env.example`.

Для проверки production-сборки:

```sh
npm run build
npm start
```

Перед передачей изменений:

```sh
npm run verify
```

Изменённые пользовательские сценарии дополнительно проходят вручную. Не храните
в приложении единственную копию важных данных до появления проверенного
восстановления из серверной резервной копии.
