# Технический прототип

Проверяет свободный ввод, локальное сохранение и базовые переходы между
расписанием, заметками и историей. Данные хранятся в IndexedDB этого браузера.
Сервер, вход и синхронизация между устройствами не подключены.

```sh
npm install
npm run build
npm start
```

Открыть адрес, напечатанный `npm start` (обычно `http://localhost:8787`).
Для офлайн-проверки сначала один раз открыть production-версию с работающим
сервером, дождаться загрузки, затем выключить сервер и перезагрузить вкладку.

Проверки перед передачей:

```sh
npm run format
npm run lint
npm run build
```

Не вводить сюда единственную копию важных данных: очистка данных браузера
удалит IndexedDB. Экспорт и серверная резервная копия пока не подключены.

На компьютере у дела есть два состояния. Щелчок или фокус выбирает дело;
↑/↓ меняет выбор, ⌘↑/↓ меняет порядок, Enter открывает редактирование.
В выбранном состоянии ⌘Enter завершает дело в Сегодня, а из будущего дня
переносит в Сегодня без запуска таймера. Escape возвращает из редактора к выбору.
⌘←/⌘→ переносит выбранное дело на соседний день, а ⌥Enter переключает
Начать / Пауза / Продолжить для дела в Сегодня. Между днями также можно
перетаскивать за ручку; цвет дела выбирается в меню `…`.
⌘Backspace / ⌘Delete убирает без истории; выбор переходит к следующему делу,
после последнего — к предыдущему, после единственного — к добавлению.
В режиме редактирования клавиши работают как в обычном текстовом поле.
В открытой заметке ⌘Enter копирует абзац под курсором в Сегодня, сохраняя источник.
Абзац ограничен переводами строки, а не переносами по ширине редактора.
Перестановка мышью — за ручку дела или карточку заметки. Для дел клавиатурная
перестановка описана выше; карточки заметок сейчас перетаскиваются указателем.

Расписание пользователя импортируется один раз через `lib/preview-schedule.ts`;
маркер хранится вместе с данными. Не сбрасывать его при загрузке: иначе удалённые
или перенесённые дела появятся снова. Существующие данные не заменяются.
В исходнике есть личные записи. Публиковать можно только в закрытом режиме.

При смене календарного дня незавершённые задачи прошлых дней атомарно переносятся
в «Дела». Задача из группы возвращается в ту же группу; остальные —
в «Не разобрано». Открытый интервал закрывается в полночь. «В Сегодня» переносит
ту же задачу обратно, сохраняя ID, цвет и накопленное время.
