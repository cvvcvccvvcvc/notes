# Версии и ветки

## Ветки

- `dev` — основная ветка разработки. Обычные изменения и исправления сначала
  попадают сюда.
- `main` — точное состояние production. Push в `main` автоматически проходит
  полную проверку и разворачивается на сервер.

Pull request в `dev` или `main` запускает CI, но ничего не разворачивает. Прямой
push в `dev` также только проверяется. Это позволяет свободно собирать следующую
версию без риска изменить production. `dev` является веткой GitHub по умолчанию.
`main` защищён от прямых и force-push, удаления и merge при незелёном `verify`.

## Номер версии

Production использует SemVer `MAJOR.MINOR.PATCH`. До `1.0.0`:

- `PATCH` — исправления без нового пользовательского поведения;
- `MINOR` — новые возможности и намеренные несовместимые изменения раннего
  продукта;
- `MAJOR` — начинается со стабильного публичного контракта `1.0.0`.

Версия хранится в `package.json` и `package-lock.json`. Не повышайте её после
каждого коммита: один номер описывает весь набор изменений очередного release.

## Выпуск

1. Убедиться, что все предназначенные для release изменения находятся в `dev`.
2. Выбрать следующий номер по полному diff от последнего production-тега.
3. Обновить оба package-файла и сделать отдельный commit вида
   `chore: prepare vX.Y.Z release`.
4. Запустить `npm run verify`.
5. Создать pull request `dev` → `main`, дождаться обязательного `verify` и слить
   его merge-коммитом.
6. Дождаться успешного workflow `Verify and deploy` и проверить production.
7. Создать на развёрнутом commit аннотированный тег `vX.Y.Z` и отправить его.
8. Fast-forward `dev` до release-коммита, если merge создал отдельный commit.

Не ставьте production-теги на `dev` и не тегируйте неудачный deploy. Версия в
package-файлах, Docker label и Git-тег должны совпадать.

## Срочное исправление

Исправление всё равно начинается от актуального `dev`. Если в `dev` уже есть
неготовая работа, создайте короткую ветку от `main`, внесите fix, выпустите новый
`PATCH`, затем обязательно влейте release обратно в `dev`. Не исправляйте только
сервер: такой код невозможно воспроизвести или безопасно откатить.
